## In short

{child}'s own screen, on a tablet at home: what's on now, {their} week, planning time, jobs and asking a grown-up. It works only on your home Wi-Fi.

## How to use it

1. Whoever set up Family time gets the tablet ready first, using the kiosk setup guide.
2. Tap Set up the kiosk here. A six-number code appears for ten minutes.
3. Type the code on the tablet. It stays set up after that, even when it restarts.

## How it works

The kiosk can plan time, say a job is done, add ideas and ask a grown-up. It can't change rules or allow or block apps. On a tablet your children share, any of them can tap the name at the top to switch. To keep each child's screen their own, set a four-number PIN for each in Settings, Kiosk; the kiosk then asks for it before opening their home. If {child} forgets it, set a new one in the same place. If you have more than one child, each child's Me page opens only with their own PIN. Me is where they add things they did and ask about rules. The kiosk calls you Mum and Dad. To change that, for example to Dad, or Nana and Grandad, go to Settings, Kiosk, What the kiosk calls you.

If a tablet is lost or handed on, tap Remove this tablet. It stops working at once and needs a new code.

## What {child} sees

If you have set a PIN, a screen to type it first. Then a hello and the time, what's on now, {their} week with Plan my time, {their} jobs with I did it, {their} savings goal and ideas, and a page that says in plain words what you can see.

## Watch out for

Leaving a code lying around. It works only once and only for ten minutes, but anyone on your home Wi-Fi with the code could set up a kiosk with it.
