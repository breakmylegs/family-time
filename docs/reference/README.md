# Reference material from my other platforms

Claude Code reads my sibling platforms (Reckoner, Estimatrix, Brightline, Clauseworks, Proscenia, P.E.T.E.R., Muster and `_shared`) to reuse their patterns. Point it at read-only clones using the SIBLING_REPOS paths in the build prompt.

If a repo is not available on this machine, put the reusable prompts I wrote for those platforms in this folder instead, as Markdown files. The useful ones are:

- `operability-standardisation.md` (health, version, logging, deployment contract, System page, audit log, retention, export)
- `backup-and-dr.md`
- `authentik-saml-sp.md` and `scim-provisioning.md`
- `sso-enforcement-maintenance-mode.md`
- `security-standardisation.md`

Rule for this folder. Reuse patterns and conventions. Only copy code verbatim from repos I personally own. Some sibling apps were built for my employer, and V2 of this platform is public.
